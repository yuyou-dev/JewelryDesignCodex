# Changelog

All notable changes to JewelryDesignCodex are documented here. The project follows [Semantic Versioning](https://semver.org/), with the usual compatibility caution for the `0.x` series.

## [Unreleased]

### Changed

- Public release preparation, portability verification, and documentation hardening.

## [0.1.1] - 2026-08-16

### Fixed

- Recover gpt-image-2 outputs deterministically from the worker `thread_id` emitted by Codex JSON events.
- Normalize Windows prompt evidence, event-hook commands, paths, and cross-drive release tests.

## [0.1.0] - 2026-08-16

### Added

- Git marketplace package `jewelry-design-codex` and core plugin `svt-jewelry-design`.
- One-prompt Codex Desktop installation Runbook with bootstrap, doctor, update, and uninstall flows.
- Local `svt_jewelry_ui` MCP with dynamic design intake, Grill Me, remix brief, visual workbench, retouch comparison, and multi-result Galleries.
- Jewelry design, remix, sketch-to-jewelry, local edit, retouch, poster, catalog, display, reference-sheet, grid, review, and model try-on Skills.
- Self-contained gpt-image-2 task preparation and generation route using the user's Codex authorization.
- macOS and native Windows support for the core install.
- Apache-2.0 source license with a separate SVT trademark policy.
